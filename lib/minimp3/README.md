# minimp3

`minimp3.h` is lieff/minimp3 (https://github.com/lieff/minimp3) at commit
`ea99364f61c14656440e8d77e9c233ccf3124633`, unmodified. It is public domain
(CC0 1.0), as the header itself says.

Used by `src/hardware/audio.cpp` to play Home Assistant's spoken replies, which
arrive as MP3. That file is the one that defines `MINIMP3_IMPLEMENTATION`.
