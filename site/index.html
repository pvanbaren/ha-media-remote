This is a fresh install. It replaces everything on the board, Wi-Fi and Home Assistant settings included. To update a remote that is already set up, use the Update page of its portal instead, which keeps them.

Before you start

  • Use Chrome, Edge or Opera on a desktop or laptop. Firefox, Safari and phones can't flash over USB.
  • Use a USB cable that carries data, not one for charging only.
  • Qualia: its USB port is run by the firmware, so the browser can't restart it into the bootloader by itself. Hold BOOT, tap RESET, then let go of BOOT, and click Install. If it does not start by itself when the install is done, tap RESET.
  • If no port is offered, unplug the board and plug it in again, or put it in download mode as for the Qualia.

After installing

  1. The remote starts on its Setup card. Tap it to choose your Wi-Fi network and type its password on the screen, or join its MediaRemote-Setup access point from a phone.
  2. Once it is on Wi-Fi, it finds Home Assistant and shows a QR code. Scan it and sign in.
  3. Choose the media player from the list, and the remote is ready.

Everything else is in the README. Firmware files for each release are on the releases page.
